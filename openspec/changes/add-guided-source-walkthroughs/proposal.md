## Why
An import graph is not a feature execution trace. Learners need a qualified, cited outline with real inputs, outputs, branches and test assertions.

## What Changes
- Add versioned bounded walkthrough views derived only from captured Python syntax, with limited states for other languages.
- Synchronize source excerpts and component highlighting, using the existing application-owned graph.
- Annotate failure constructs and captured tests without executing them.

## Capabilities
### New Capabilities
- `source-walkthroughs`: guided reading of saved feature boundaries.
### Modified Capabilities
None.

## Impact
Learning service, routes/templates/browser code and synthetic tests. No universal call graph or new renderer dependency.
