## ADDED Requirements

### Requirement: Evidence-qualified educational checks
The project SHALL verify saved citation scope, substantive examples, limited language coverage and alternate design reasoning using synthetic fixtures, while distinguishing real educational acceptance.

#### Scenario: Unsupported feature trace
- **WHEN** a synthetic mixed-language or DAZ review lacks supported runtime tracing
- **THEN** the learning view labels unsupported coverage and does not invent execution or deployment

### Requirement: Quiet headless acceptance
The project SHALL exercise the learning flow through a task-owned isolated headless server without models, visible windows or modifications to real projects.

#### Scenario: Provider failure during practice
- **WHEN** the fake instructor fails or a learner cancels
- **THEN** the draft and selected origin remain available and no successful answer is fabricated

### Requirement: Honest release readiness
The project SHALL retain required Windows and installed-release gates and record unfinished external checks explicitly.

#### Scenario: Live or desktop gate not authorized
- **WHEN** a required gate needs model inference, rendering or visible launch without an explicit request
- **THEN** that gate remains pending and the release is not described as fully verified
