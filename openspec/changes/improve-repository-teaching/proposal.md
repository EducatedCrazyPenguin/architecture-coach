## Why

Saved reviews suppress generated lessons when quizzes exist, print internal IDs in the main path, and do not identify question concepts. A learner needs source-grounded explanations beside practice.

## What Changes

- Add a learning start and readable main-path names and provider labels.
- Expose saved lessons and validated source excerpts alongside quizzes and in newly generated exports, preserving existing artifact bytes.
- Add compatible concept/difficulty metadata to questions and improve generation guidance.

## Capabilities

### New Capabilities
- `repository-teaching`: evidence-grounded teaching and practice in saved reviews.

### Modified Capabilities
None.

## Impact

Review models, critique schema/prompts, versioned fingerprints, templates, export endpoint, and synthetic tests. No new dependency or real provider calls.
